- **Install with Homebrew or winget.** On macOS, `brew install --cask plenarius/tap/nwn-landscaper`; on Windows,
  `winget install Plenarius.NWNLandscaper`. Publishing a release updates both (`.github/workflows/packages.yml`). See
  [Install on macOS](../docs/handbook/install-macos.md) and [Install on Windows](../docs/handbook/install-windows.md).
